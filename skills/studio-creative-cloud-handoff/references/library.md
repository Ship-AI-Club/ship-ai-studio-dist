# Creative library map

The full Studio skill and reference library stays available to every creative run. Read it progressively: find the need below, open that skill, read only the sections this asset needs, and record it in the creative brief's `reads`. Resolve every skill through this Studio catalog (`catalog.json`). Never load a skill from another plugin or an older product-team copy.

Every row below is in this release's catalog. A row marked `after Product import` would not be: skip it and work from the rows marked `in this release`.
