# About the actual business

## 0. Resolve

From this folder run `node ../../scripts/resolve-studio.mjs --skill studio-about-page`. Send the JSON to the PM. Stop on any error; never load an older product-team skill instead.

Read the shared questionnaire, approved positioning, product brief and brand. Use the actual copywriting and copy-editing skills. Ask only for missing facts that materially help the page.

Explain who the business serves, why it exists, what it provides and how it works. Use verified origin, people, expertise, approach and credentials when available. Never invent a founder, team photo, biography, values, founding date, customers, social proof, metrics or a mission the owner did not express. If facts are unknown, omit them or ask the PM; do not fill with generic claims.

Write about.headline, body paragraphs and optional fact sections in brief/project.json with status draft. Match B2B buyer/end-user context or B2C customer context and the approved offer. The next action must fit this business. Let Designer review the rendered page and the owner approve the facts and copy. Only then set status approved. No fabricated Organization/Person schema.
