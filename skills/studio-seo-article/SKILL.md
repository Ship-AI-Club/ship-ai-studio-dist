# A useful SEO article

## 0. Resolve

From this folder run `node ../../scripts/resolve-studio.mjs --skill studio-seo-article`. Send the JSON to the PM. Stop on any error; never load an older product-team skill instead.

Read .agents/product-marketing.md, the approved positioning/PM scope and existing content first. Apply content-strategy, copywriting, copy-editing and SEO audit from the bundled upstream pack. Ask only for missing decisions.

Choose one topic that matters to this customer and matches actual search intent. Research primary/reliable dated sources, explain what each supports and identify an original useful angle. Do not invent volume, rankings, first-hand expertise, author credentials, examples or results. B2B/B2C changes the buying context, language and next step; it is not a reason to use stock phrases.

Propose title, intent, audience, main answer, outline and sources. Draft in articles in brief/project.json with status draft, a unique slug/title/description, actual author/review date, sourceIds and useful sections. Use specific examples only when sourced or explicitly labelled hypothetical. Add related internal links and a CTA that fits the approved journey. Show the complete rendered article for feedback. Apply changes and get owner/editor approval before status approved. Do not auto-publish or mass-generate articles. Report source gaps honestly.

The validator checks structure only. Review helpfulness, factual accuracy, distinct value and claim support yourself. Keep the business's voice. Adapt structured sections/components if the article needs richer legitimate content rather than flattening it into generic filler.
